1전체 흐름과 좋은 프롬프트

설계 학습지에서 만든 ‘만약 ~이면’ 규칙이 프롬프트의 재료가 돼요.

설계 규칙 정리→프롬프트 조립→코파일럿에 보내기→MakeCode 자바스크립트에 붙여넣기→블록·시뮬레이터 확인→기기에서 시험→고쳐 달라고 다시 묻기

이렇게 물으면

마이크로비트로 주차장 차단기 코드 만들어줘

파이썬으로 줄 수도 있고, 핀 번호와 각도를 마음대로 정해요. 우리 모형과 맞지 않는 코드가 나오기 쉬워요.

이렇게 물으면

MakeCode for micro:bit 자바스크립트로 써 줘. 초음파 센서(Trig P1, Echo P2), 서보모터(P0)를 쓴다. 만약 거리가 10cm보다 가까우면 서보를 90도로 돌리고, 3초 뒤 0도로 돌린다. 블록으로 바뀌는 문법만 써 줘.

환경, 부품, 핀, 규칙, 기준값이 분명해서 바로 붙여 넣어 시험할 수 있는 코드가 나와요.
