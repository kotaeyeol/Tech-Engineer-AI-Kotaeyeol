고1 기술 · DEV / STARTUP / AI 02 · TINKERCAD 접속

접속하고, 캡처로 기록해요

  1. Tinkercad 열기 ↗ · 학교 계정이나 선생님이 안내한 수업 링크로 접속해요.
  2. 새 3D 디자인을 열고 자유롭게 작품을 만들어 보세요.
  3. 완성한 작품이 잘 보이도록 화면을 돌린 뒤 화면 캡처를 해요. Windows: Win + Shift + S / Mac: Shift + Command + 4
  4. 오늘의 과제에서 해당 이미지 칸을 선택하고 캡처를 붙여넣어요. 저장된 캡처 파일을 선택해도 좋아요. AI 제품 이미지도 캡처해서 옆 칸에 넣어요.
붙여넣기: Windows는 Ctrl + V, Mac은 Command + V. 계정 정보나 다른 사람의 얼굴이 보이지 않도록 작품 부분만 캡처하세요.

네 군데만 먼저 찾으세요

01

작업 평면

도형을 올려놓는 바닥. 격자와 치수를 보며 배치합니다.

02

기본 도형 목록

상자(Box), 지붕(Roof), 원기둥(Cylinder)을 끌어옵니다.

03

보기 도구

뷰 큐브로 앞·위·오른쪽 보기. 홈 보기와 확대·축소를 사용합니다.

04

도형 · 편집 도구

솔리드/구멍, 그룹/그룹 해제, 정렬을 찾아봅니다.

30초 확인 · 상자 하나를 놓고, 앞에서 보기 → 위에서 보기 → 홈 보기로 돌아오기.
고1 기술 · DEV / STARTUP / AI 02.2 · 기본 조작

도형 하나로 조작 연습

01

크기

도형 선택 → 크기 조절점 클릭 → 가로·깊이·높이 숫자 입력

02

이동 · 높이

바닥에서 끌어 이동. 위쪽 검은 높이 조절 핸들로 띄우기.

03

회전 · 복제

곡선 화살표로 회전. 복제 도구로 같은 도형을 하나 더 만들기.

04

정확한 치수

자(Ruler)를 작업 평면에 놓으면 위치와 크기를 숫자로 확인하기 편해요.

따라 하기 · 상자를 30 × 20 × 10 mm로 변경 → 복제 → 원본 옆에 이동 → 복제본을 45° 회전해 보기.
고1 기술 · DEV / STARTUP / AI 02.3 · ALIGN / GROUP / HOLE

더하고, 맞추고, 빼기

01

정렬 = 위치 맞추기

Shift로 두 도형 선택 → 정렬(Align) → 가로·깊이의 가운데 점을 선택

02

그룹 = 하나로 다루기

여러 솔리드를 선택해 그룹(Group)하면 한 덩어리처럼 이동할 수 있어요.

03

구멍 = 겹친 부분 빼기

뺄 도형을 구멍(Hole)으로 바꿔 솔리드와 겹친 뒤 그룹합니다.

중요 · 구멍 도형은 화면에만 놓으면 뚫리지 않아요. 반드시 빼고 싶은 솔리드와 함께 선택해 그룹해야 합니다.
